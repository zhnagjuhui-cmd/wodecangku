# 任务契约
共同：只在归属目录新增项目文件，保留已有文件与分支；不使用患者隐私；记录来源定位、提取日期、版本和核验者。无法核实用 UNVERIFIED；数值缺失用 null / 空字段并附原因，禁止用0代替。

A 输入为原始论文/官方补充/ClinicalTrials.gov；输出研究卡、来源账、逐字段核验与冻结清单。摘要只支持摘要可见信息，不能宣称全文核验；协议不能代替结果论文；注册当前记录与历史协议差异须留痕。

C 独立建立 study_extraction 并提取，输出数据字典、原始/派生值、单位、终点层级、分析人群、时间点、CI/P值/缺失处理/来源定位；派生值记录公式，不以显示值倒推未报告数字。与 A 差异必须升级总控，不能自行覆盖。

B 仅消费经签署的 A 冻结包和 C 已验收数字；输出原生可编辑课件、中文备注、逐页引用及渲染检查。等待期间只能建 README、验收清单和门禁，不制作医学内容。

验收分别记录 A/C/B 审核结果与未解决问题，最终总控验收不可代替独立学术复核。不同研究的终点、随访和人群不得未经论证作疗效排名或汇总。
