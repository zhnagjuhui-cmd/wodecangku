# 医学PPT文献原图更新

交付可追溯、可继续编辑的医学演示文稿。按用户当前请求选择整理、找文献、原图替换、讲稿或资料包同步；不要因为调用此技能就扩展所有工作。

## 确定当前基线

- 以用户最新指定的文件为准，读取实际页数、页序、尺寸、备注与图表结构，不从文件名推断页数。
- 建立物理页码与页脚编号的映射。中间目录、章节页可能使两者偏移。
- 局部更新沿用原版式，保留未修改页和源文件。新交付另存版本，说明原图是图片、哪些内容原生可编辑。
- 照片/扫描页先定位投影屏幕，去掉人物与环境，校正透视，再识别文字及分面。不能用整页照片或九宫格假装完成重构。
- 实际PPT制作遵循当前可用的 `presentations` 技能；重构图片时按需读取 `ppt-image-reconstruction`；PDF读取按需使用 `pdf`。缺少配套能力时报告实际限制，不编造完成。

## 建立文献与页面对应关系

1. 从正文、页脚、备注和照片中收集题名、作者、年份、DOI、PMID。未辨认的字保持待核实，不补造题录。
2. 为每条引用记录：对应物理页/页脚、研究人群、设计、主要终点、时间、全文状态、版本、图号/面板、文件路径与来源。
3. 先检查用户提供文件、本任务下载目录及用户指定本地文献库，打开正文核对题名和DOI。搜索命中参考文献中的DOI，不等于该文件就是目标论文。
4. 云端占位、无文本扫描件与可读取PDF分开计数，不将未检索文件报告为不存在。
5. 按需从PubMed定位正式题录，跟进出版社、PMC/Europe PMC、机构或作者开放存档。PubMed题录/摘要不等于全文。下载后核验PDF签名、可解析页数、题名和DOI；HTTP 200可能是登录、验证或简介页。
6. 遇到订阅/验证限制，检查合理的开放来源后停止重复重试，保留入口和失败原因；不绕过访问限制或把相关综述当作缺失论文。

状态分类与证据解读细节见 [references/evidence.md](references/evidence.md)。后续收到新文件时，先匹配同一研究；不同人群/终点的相关研究只能放在合适背景，不能直接替换原研究。

## 替换原图与更新结果

- 优先论文正式原图，其次明确标注的会议原图。获取PDF时按原始页面区域高分辨率裁切；保留完整坐标、单位、图例、误差条、样本数和分面标识。
- 每个结果核对分析人群、终点、时间及统计方法。主要分析、次要分析、插补分析、事后排除、开放标签延长期分开。
- 原始曲线不可得时，只忠实重绘已核实的汇总终点，并标明来源层级。不能推算时间轨迹、置信区间或个体点。
- HRCT和病理使用真实医学图像，研究结果图不由AI伪造。生成式图片仅用于用户要求的非数据概念插图，并标明性质。
- 原图与正文单位或数据有冲突时保留原图，核对是否有勘误；未解决的差异明确注明，不静默修正。
- 在该页备注记录准确的DOI、图号/面板、PDF页码、版本和影响结论的限制。

## 演讲者备注

用户要求全稿时逐页生成，包含封面、目录及总结。用自然中文讲稿说明本页主题、如何读图、关键结果、证据局限和必要过渡，附来源。避免仅复制页面文字或只写“原文已核验”。篇幅根据演讲时长和内容决定，不给每页设置机械字数下限。

将备注真正写入PPT的每页speaker notes，并按slide→notes关系核验一一对应、正文完整。另附可独立阅读讲稿。对保留的旧页面也要检查讲稿是否夸大页面证据。

## 验证与同步交付

- 检查总页数、页序、原图清晰度、文本溢出、脚注和备注。渲染修改页逐页复核，并检查其他页是否意外变化。
- 局部OOXML替换必须跟随关系ID、相对/绝对路径及Content Types，不能按ZIP枚举顺序匹配图表。图表和下方解释左右对应要目视确认。
- 现有嵌入工作簿及公式优先保留；仅在明确发现链接错误且能核对源工作簿时修复，不用猜测的快照替代真实数据。
- 交付检查与具体包结构见 [references/delivery.md](references/delivery.md)。包内最新PPT、讲稿、补充原文和清单必须来自同一版本；旧记录标注历史状态，不能在当前清单仍把已补齐全文列为缺失。
- 可运行 `python3 scripts/package_release.py <待打包目录> <新ZIP路径>` 生成含文件哈希的资料包并检查ZIP。脚本不处理文献质量或PPT视觉验证，不能以打包成功代替内容核验。

报告真实已完成内容以及仍缺的文献/版本；不把HTML缺PDF与完全缺正文混为一类。只有打开并检查原生PowerPoint后才能声称通过PowerPoint验证。
