# 验收与交付清单

## 证据 QA

- [ ] 关键结论都有页内引文。
- [ ] 研究设计、样本量、人群、终点、时间点和关键数据准确。
- [ ] HR/OR/RR、绝对差、变化值、CI 和 P 值未混淆。
- [ ] 直接、桥接、背景、探索性和仅摘要证据已标注。
- [ ] 阴性结果、提前终止、缺失值处理和主要局限未被隐藏。
- [ ] 无跨试验头对头比较、因果夸大或无依据的超说明书宣传。

## 视觉 QA

- [ ] 全部页面已渲染为图片并逐页查看。
- [ ] 中文字体正常，无乱码、替换字形和文本溢出。
- [ ] 无遮挡、裁切错误、低清原图或无法辨认的引文。
- [ ] 标题层级、边距、酒红与青绿色使用一致。
- [ ] 图表轴、图例、组别、数值、误差/CI 和统计标识完整。
- [ ] 青绿色结论条与本页证据一致。

## 可编辑性 QA

- [ ] 标题、正文、引文、结论条和结构形状为原生对象。
- [ ] 论文复杂图为独立图片，而不是整页背景。
- [ ] 没有只有一张全页图片、缺少原生文本的幻灯片。
- [ ] 流程、表格和简单图表可在 PowerPoint 中直接编辑。

## 结构 QA

- [ ] 实际页数与批准页数一致。
- [ ] 每页都有非空且与页面一致的中文讲者备注。
- [ ] PPTX 可作为 ZIP 完整读取并能正常打开。
- [ ] 目录、大纲、页码、备注和最终文件相互一致。
- [ ] 已运行 `scripts/validate_pptx.py`，错误为 0。

## 交付说明

交付时给出：

- 最终 PPTX 的绝对路径；
- 证据目录与素材目录；
- 页数、备注页数、验证脚本结果；
- 逐页视觉检查是否完成；
- 仍为仅摘要、全文受限或无法核实的内容；
- 任何仍为位图且无法原生编辑的必要论文图。

不要把“已生成文件”当作“已验收”。只有经过打开、渲染、逐页检查和结构验证后才算完成。
