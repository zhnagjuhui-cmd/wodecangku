# Reconstruction Workflow

## Scope

Use this workflow when rebuilding a slide-like image into editable PPT.

## 1. Inspect

- Classify the source as screenshot, GPT image, scan, poster, or mixed layout.
- Identify titles, panels, charts, tables, notes, footers, and citation blocks.
- Decide whether one source page should become one slide.

## 2. Plan Layers

- Background surfaces
- Structural shapes
- Native text
- Cropped panel images
- Native tables
- Conclusions
- References and footnotes

## 3. Build Order

1. Slide bounds
2. Background blocks
3. Panel frames
4. Titles and labels
5. Tables
6. Cropped panels
7. Conclusions and highlights
8. References and footnotes

## 4. Rebuild Rules

- Use native text for readable text.
- Use native shapes for boxes, arrows, labels, and dividers.
- Crop panels independently.
- Rebuild tables natively when possible.
- Keep conclusions and references separate.
- Avoid a full-page image background unless explicitly requested.

## 5. Sample-First Policy

- Rebuild one representative page first.
- Review fidelity and editability.
- Then continue page by page.

## 6. Output Check

- Native text
- Native shapes
- Cropped images
- Native tables
- Uncertain regions
- Extra footer or citation space
- Whether the page is safe to continue
